# 方法选择与诊断

本文件是设计检查表，不是估计软件说明书。执行前查对应版本官方文档和论文；记录包版本、估计量、目标量、比较组、权重和标准误。

| 场景 | 设计核心 | 必须检查 | 不能据此宣称 |
|---|---|---|---|
| OLS/面板FE | 条件相关或可信外生变异 | 组内变异、共线性、单例、聚类与遗漏因素 | 加FE就消除全部内生性 |
| 同期DiD | 平行趋势、无预期和干扰范围 | 政策前动态、样本构成、同期冲击、处理强度 | 前趋势不显著证明平行趋势 |
| 分期DiD | cohort-time ATT及聚合权重 | never/not-yet treated、支持区间、预期、尾部合并 | 普通TWFE必然等于ATT |
| IV | 相关性、排除、独立性和单调性 | 第一阶段、约化式、匹配误差结构的弱识别诊断、弱IV稳健区间 | F>10普遍安全或过识别检验证明有效 |
| RDD | 阈值附近连续性或局部随机化 | sharp/fuzzy、方向、带宽、偏差校正推断、密度/协变量、质量点 | 全样本高阶多项式提供稳健因果效应 |
| SCM/SDID | 可信供体和处理前拟合 | 供体污染、预期、预拟合、安慰剂可比性、少处理单位推断 | 用普通大样本t检验即可 |
| 随机实验 | 分配和实际接受不同 | ITT、失访、依从、分层/簇随机、随机化推断 | 按实际接受回归保留随机性 |

## 软件分支

Stata：FE 可评估 reghdfe，分期DiD 可评估 csdid/did_imputation，IV 可评估 ivreg2/ivreghdfe，RD 可评估 rdrobust/rddensity。使用 `which`、本地 help 和官方仓库确认依赖与返回值。

R：FE/部分事件研究可评估 fixest，group-time ATT 可评估 did，RD 可评估 rdrobust。保存 sessionInfo；不要把不同包默认权重下的参数视为同一目标量。

Python：常规面板可评估 linearmodels，固定效应和部分因果方法可评估 pyfixest。核对功能及版本，不以手写简化版替代成熟估计量并宣称等价。

匹配/加权需要重叠、平衡和可忽略性论证；不能解决不可观测混杂。预测/机器学习采用训练验证隔离；因果ML需说明 nuisance、交叉拟合和目标参数。方法不在本表时先建立方法备忘录再估计。

## 推断

记录有效簇数和簇大小分布；少簇考虑适用的 wild cluster bootstrap、随机化推断或其他小样本修正，并说明适用条件。标准误层级由设计决定。权重区分抽样、频数和精度含义。空间相关或序列相关按具体结构处理。

动态效果需固定基期、事件窗口、尾部和置信区间；报告cohort支持和每期样本。不只展示显著事件期。
