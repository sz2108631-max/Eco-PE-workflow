# 数据与复现协议

## 目录

唯一主入口 master.do / master.R / master.py；code 按导入、清洗、变量、样本、描述、主估计、诊断、扩展、导出分阶段；data/raw 只读，intermediate 和 analysis 可再生；outputs/tables、outputs/figures 保存研究产物；logs 与 audit 保存证据。

## 数据契约

每份源数据记录来源URL/本地来源、访问日期、许可、文件哈希、观测单位、主键、时间和变量字典。大文件流式计算哈希。导入时检查编码、数值解析和缺失码。面板检查单位×时间唯一性、缺口、处理状态反转及进入退出。

合并审计包含左右输入、键、预期基数、左右重复数、匹配数和两侧未匹配数；明确保留规则。样本流水包含 stage、reason、before、excluded、after，连续步骤满足 before-excluded=after；多条互相重叠限制按实际执行顺序记账。

变量字典记录来源、单位、公式、缺失与异常处理。禁止默认缩尾1%或把缺失补零。处理时点必须能追溯到政策文件或分配记录。

## 环境与执行

使用相对项目根目录路径；记录 OS、软件、包版本、随机种子和依赖安装说明。优先项目局部依赖。网络获取与估计分离，避免重跑时源数据变动。主程序遇核心错误返回非零；不得用捕获错误掩盖失败。

## 复现

1. 保存输入指纹及版本信息。
2. 全新会话从主入口运行；检查退出码和日志。
3. 重复运行比较样本量、点估计、SE、CI与输出清单。
4. 若跨语言核验，先对齐样本、权重、FE、自由度修正和目标量；解释差异。
5. 写入 audit/run_report.md：通过/失败/未验证、容差、差异、偏离、下一步。

受限数据项目提供数据申请和目录映射说明；可用模拟数据验证程序结构，但模拟结果须显式标记，不进入论文证据。
